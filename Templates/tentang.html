Tentang Proyek Ini

Latar Belakang

Kode warna hexadecimal (#RRGGBB) banyak digunakan dalam pengembangan web, desain antarmuka, dan pengolahan gambar digital. Kesalahan format kode warna misalnya jumlah digit yang kurang atau karakter yang tidak valid dapat menyebabkan tampilan tidak sesuai atau bahkan program mengalami error. Studi kasus ini mengangkat permasalahan tersebut sebagai penerapan konsep Deterministic Finite Automaton (DFA) untuk memvalidasi format string secara otomatis.

Tujuan Aplikasi

  • Menerapkan konsep DFA untuk memvalidasi format kode warna hexadecimal secara real-time.
  • Memvisualisasikan cara kerja DFA melalui diagram state interaktif, sehingga konsep otomata lebih mudah dipahami secara visual.
  • Menguji keandalan DFA menggunakan dataset nyata yang berisi ribuan kode warna.
